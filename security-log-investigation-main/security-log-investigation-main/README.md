# Security Log Investigation Task

This repository contains the investigation notebook, normalization script, detection rules, and final incident report for the **Security Log Investigation** task.

- **[Dataset](./data/synthetic_authentication_log.csv)**: Synthetic authentication event records analyzed during the investigation.
